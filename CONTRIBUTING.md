# Contributing

Thanks for your interest! Issues and pull requests are welcome.

- **Bugs / ideas:** open an issue with your hardware (SDR board and firmware version from `VERSION?`, sniffer), OS, the command line you used, and the relevant part of the console log.
- **Pull requests:** keep them focused. Describe how you tested, ideally on real hardware, and include numbers for performance changes (fps, CRC errors, CPU).
- **Style:** Python 3.10+, standard library + numpy; keep the dashboard a single dependency-free page (`sniff_sight/web.py`). All UI text and docs in English.
- **Never commit** captures (`*.pcap`, `*.npz`, `*.csv`), auth files, network keys or host-specific paths. `.gitignore` covers the usual ones.
- By contributing you agree that your contribution is licensed under GPL-3.0.
